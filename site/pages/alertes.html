Comment faire

  1. Installez Telegram si vous ne l'avez pas : application gratuite sur téléphone ou ordinateur (telegram.org).
  2. Ouvrez le canal avec le bouton ci-dessus, puis touchez « Rejoindre ».
  3. C'est tout. Pour arrêter : « Quitter le canal ». Vous pouvez aussi couper les notifications et lire les messages quand vous voulez.

Sans Telegram, vous pouvez retrouver chaque vote sur ce site, à partir de l'accueil ou de l'onglet Scrutins.

Vos données

Ce site ne reçoit aucune information sur vous : pas d'inscription, pas d'adresse, pas de numéro. L'abonnement est géré entièrement par Telegram, selon ses propres conditions. Les abonné.e.s d'un canal ne voient pas les autres abonné.e.s ; l'éditeur, en tant qu'administrateur, ne consulte ni n'exploite la liste des abonné.e.s.
