    Comment lire un vote

    1. Le résultat : adopté ou rejeté, avec le nombre de voix pour, contre et d'abstentions.
    2. L'hémicycle : chaque point est un député, à sa place réelle, coloré selon son vote. Survolez ou touchez un point pour voir qui c'est.
    3. Le débat en bref : pour les votes sur l'ensemble d'un texte, les principaux arguments pour et contre, cités mot pour mot.

    Seuls les scrutins publics indiquent le vote de chaque député : les votes à main levée n'apparaissent pas. Questions fréquentes · Méthodologie
